# Bounded public research adapter

`packages/foundry/src/operations/research.ts` provides a real, read-only public-document adapter. It does not call a search provider, a model provider, a credential store, or a paid service.

Create it with one or more explicit `seedUrls`. The seed hosts are the complete authority boundary. A worker can retrieve a seed, inspect its source-backed links, choose one observed in that fetched corpus, retrieve it, run `dynamic_query` against the locally fetched corpus, and obtain an `evidence` record by source ID. A query never fetches a URL and never produces an answer or diagnosis.

Every successful retrieval retains an immutable observation: `id`, final `url`, `observedAt`, `contentHash`, direct `sourceAssertion`, extracted `links`, public-readonly rights, and a revision link if the URL later changes. The adapter only extracts HTML, XHTML, plain text, and Markdown. PDFs, ebooks, images, audio, and video are reported as unsupported without extraction.

The adapter validates every initial URL and every redirect: HTTPS only, port 443 only, no URL credentials, no localhost/metadata/private address literals, exact configured seed hosts only, and DNS answers must all be public before a request. DNS is subject to the same deadline, rejects loopback/private/link-local/CGNAT/reserved/multicast IPv4 and local/mapped IPv6 forms, and the production HTTPS transport pins its lookup callback to the vetted address. That closes the native `fetch` re-resolution/rebinding gap. Redirects are fetched manually and are checked again. Injected fetch ports exist only for deterministic tests and receive the vetted address; they are not a production transport. It sends a fixed public-reader request header set with no cookies, authorization, caller headers, or credentials. The request cap counts failed requests and redirects as well as successful sources. Page count, redirect count, response bytes, extracted text, links, and deadline are explicitly bounded and validated. A deadline races non-cooperating fetch implementations as well as aborting cooperative ones.

This uses Node's built-in `https.request`, `Readable.toWeb`, and `AbortController`; no HTML parser or network dependency was added. The HTTPS request receives a custom lookup callback with the vetted address, while Node's abort primitives impose the bounded deadline: [Node global objects](https://nodejs.org/api/globals.html), [Node HTTPS API](https://nodejs.org/api/https.html). The adapter uses a local `AbortController` because it also races a deadline around dependency-injected fetches used in deterministic tests.

The `operations-research.test.ts` suite uses only fake DNS and fake fetch functions. It covers text/link extraction, corpus-only querying and evidence, hostile and redirected URLs, private/CGNAT DNS, vetted-address handoff, DNS/response deadlines, failed-attempt caps, byte/document limits, and content revisions. It makes no real public request.
