**Pricing and route evidence**

At 32,768 input and output tokens, ordinary uncached token pricing is $1.96608, rounded up to $1.97. Using the published cache-write input rate gives $2.048, rounded up to **$2.05**. The proposed route matches the current code: `gpt-6-astra`, `reasoning.effort=max`, `service_tier=default`, 32,768 counted input tokens, 32,768 maximum output tokens, one provider request at a time and zero automatic retries. Max is a supported public setting; no Ultra support or immutable snapshot is inferred. Access for the owner's specific API project has not been verified. Final approval must cover this Max route explicitly. A serialized request proves the requested settings; the evidence report must separately retain the returned model, service tier, token usage and provider request identity, and mark unobserved settings as unverified.

The $6.90 allowance is an explicit proposal, calculated at five cents per maximum admission. It is not an official price for counts or retrievals. The existing ledger can reserve and retain unknown exposure, but this document does not establish a hard invoice bound for unpriced endpoints or taxes. Report actual known, provisional and unknown amounts separately and reconcile billing evidence when available. The cap is a decision limit, not a spending target or an expected invoice.

The proposed overall active execution limit is 48 hours within an approved absolute seven-day grant window. An included Codex route is a possible later alternative, not the currently approved execution route. The native route failed isolation and is unsuitable.
